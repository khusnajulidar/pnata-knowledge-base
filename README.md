## Status
- ACTIVE / DISETUJUI: keputusan berlaku.
- SUPERSEDED / DIGANTIKAN: hanya untuk sejarah; jangan diikuti jika bertentangan.
- DRAFT / PERLU VERIFIKASI: bukan keputusan final.
- Status di sini adalah rekonstruksi dari GitHub; periksa sumber sebelum mengubah produk.
