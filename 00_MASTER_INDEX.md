## Ringkasan
P'Nata adalah merek media belajar anak. Portofolio yang ditemukan mencakup game edukasi digital dan activity book/worksheet. Prioritas lintas proyek: ketepatan materi, pengalaman anak yang mudah digunakan, identitas visual ceria, dan dokumentasi keputusan.

## Proyek teridentifikasi
1. **Yuk Belajar Adab Makan** — game web usia 3–4 tahun; 5 misi, 25 aktivitas.
2. **Petualangan Cinta Rasul** — game HTML SD kelas 1–6; 3 wilayah, 3 mode, 9 tantangan utama + 1 bonus.
3. **Petualangan Huruf Hijaiyah** — game interaktif usia 4–8 tahun; beberapa versi HTML dan paket audio 29 huruf.
4. **Yuk, Belajar Salat!** — activity book 10 halaman kelas 1–2 SD; H1–2 disetujui, H3 perlu review, H4 konsep disetujui, H5–10 belum final.
